# Contributing

Thanks for helping make this the best open interview-prep set for **Agentic Design Patterns**.

## What we want

- Deeper failure modes, metrics, and “when NOT to use”
- New interview Q&As (with solid answers)
- Production checklists and system-design sketches
- Fixes for outdated protocol/framework notes
- Better diagrams (ASCII/Mermaid)

## What we do **not** want

- Verbatim copyrighted book text
- Live company interview questions under NDA
- Malware, exploit PoCs, or unsafe dual-use details
- Drive-by dependency / tooling churn unrelated to notes

## How to contribute

1. Open an issue first for large changes (`content-gap` or `question` templates).
2. Fork → branch → edit Markdown in place.
3. Keep the section contract for pattern files:
   - `## Interview Answer (60–90s)`
   - `## Deep Dive`
   - `## Common Interview Questions`
   - `## Anti-Patterns`
   - `## Production Checklist`
4. Prefer trade-offs over hype. Cite public docs/papers when making strong claims.
5. Open a PR using the PR template.

## Style

- Practical, precise, interview-ready
- Short ASCII/Mermaid diagrams OK
- Pseudocode / Python / TypeScript snippets OK
- Bold sparingly; lead with the answer

## Local preview

Any Markdown viewer is fine. No build step required.
